# Filing360

Design-first Next.js marketing site for an Indian company registration and compliance marketplace.

## Develop

```bash
cd karya
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Brand

Brand strings live in `src/lib/siteConfig.ts`. Colors are in `src/app/globals.css`.

## Stack

Next.js App Router, Tailwind CSS v4, Motion, Fraunces + Geist.
